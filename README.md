## 📝 Описание проекта
Данная работа представляет собой программно-аппаратный комплекс для автоматизации жилых и учебных помещений. Основной акцент сделан на автономности, отказоустойчивости и устранении зависимости от коммерческих облачных сервисов. 

Система построена на базе локального сервера **Home Assistant** и периферийных узлов под управлением **ESPHome**.

## 🛠 Технологический стек
* **Сервер:** Raspberry Pi 4 (Home Assistant OS)
* **Микроконтроллеры:** ESP32, ESP32-CAM
* **Прошивка:** ESPHome (YAML-конфигурации)
* **Связь:** Wi-Fi (локально), GSM (SMS-оповещения), RFID (доступ)

## 🌟 Ключевые функции

### 🛡 Безопасность и контроль доступа
* **RFID-авторизация:** Вход в систему по картам/меткам через считыватель RC522.
* **GSM-информирование:** Отправка экстренных SMS через модуль SIM800L при срабатывании датчиков.
* **Видеомониторинг:** Стриминг видео в реальном времени через ESP32-CAM (с поддержкой PSRAM).
* **Сигнализация:** Звуковое и SMS-оповещение при несанкционированном доступе.

### 💨 Техногенная безопасность и климат
* **Контроль утечки газа:** Автоматическая активация вытяжной вентиляции при обнаружении опасных концентраций (MQ-сенсоры) и отправка SMS-оповещения.
* **Автоклимат:** Поддержание заданной температуры посредством управления вентилятором.
* **Голосовое управление:** Возможность интеграции с голосовыми ассистентами через Home Assistant (Алиса и аналоги).

## 📂 Структура репозитория
* `main-hub.yaml` — Конфигурация центрального узла (безопасность, климат, GSM).
* `camera-hub.yaml` — Конфигурация узла видеонаблюдения.

## 🚀 Установка и развертывание

1. **Подготовка системы:** Установите **Home Assistant** на Raspberry Pi или ваш компьютер и добавьте аддон **ESPHome**.
2. **Настройка секретов:** В ESPHome во вкладке `SECRETS` укажите ваш Wi-Fi SSID и пароль.
3. **Создание конфигурации:** В панели ESPHome нажмите «New Device» и дайте ему имя (например, `main-hub`).
    * Выберите тип платы (ESP32).
    * **Важно по коду:** ESPHome создаст базовый шаблон. Скопируйте код из нужного YAML-файла репозитория, начиная со строки `captive_portal:`. 
    * **Сохранение ключей:** При вставке обязательно сохраните в своём новом конфиге уникальные блоки `api: encryption:`, `ap:` и `ota:`, сгенерированные системой — это ваши личные ключи доступа.
    * **Специфические настройки:** Но перенесите блоки `text_sensor:` и `api: services:` (для main-hub) и блок `psram:` (для camera-hub) до строки `captive_portal:` для корректной работы компонентов.
4. **Прошивка:** Подключите устройство к компьютеру по USB (при первой прошивке), скачайте соотвествующий YAML-файл и загрузите его через [web.esphome.io](https://web.esphome.io). Если устройство уже в сети, можно использовать прошивку «по воздуху» (OTA).

**P.S.** Данная информация по установке является ознакомительной. При первом знакомстве с Home Assistant и ESPHome настоятельно рекомендую использовать официальные источники: [home-assistant.io](https://www.home-assistant.io/) и [esphome.io](https://esphome.io/).
